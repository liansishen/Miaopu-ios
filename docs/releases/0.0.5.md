喵扑 iOS 0.0.5。

- 首页刷新按钮移到导航栏右上角，与赛事页保持一致。
- 赛事页收紧日期条与项目选择行之间的间距，顶部安全区与滚动内容的上边距清零。
- 仓库采用 MIT 许可证，README 按安卓版结构重写，补充参考说明、致谢与 LINUX DO 友情链接。
- CI 只在影响编译的路径变化时运行，文档与许可证改动不再触发。

附件 `Miaopu-0.0.5-unsigned.ipa` 为 **未签名 IPA**，需由使用者自行签名后安装；`.sha256` 文件用于校验下载完整性。

本版通过 macOS CI 的 24 项单元测试、iOS 模拟器界面测试、iPhoneOS 构建、无签名校验与图标校验。按既定安排不做实机验证：真实账号下的评分与评论提交、设备小组件与相册权限行为需在签名安装后确认。技术统计接口对已结束的多数场次返回空数据，相应标签不会出现。当前覆盖五类赛事，更新检查尚未实现。
