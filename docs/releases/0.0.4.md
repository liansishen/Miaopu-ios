喵扑 iOS 0.0.4：补齐应用图标并优化赛事页。

- 新增应用图标：此前工程没有任何图标资源，安装后桌面显示空白图标；现提供 1024 像素图标（橙色渐变底、白色「喵」字），并在打包脚本中校验包内必须包含图标资源。
- 赛事页新增「跳到今天」按钮：没有当天赛程时跳到之后最近的一天。
- 赛事页右侧新增日期快速滚动条：按下显示跟随手指的日期提示，拖动可按日期连续定位；日期分隔条同时显示当天场次数量，今天用强调色圆点标记。
- 赛事页工具栏新增刷新按钮，与下拉刷新一致地强制重新加载当前项目。
- 仓库改为公开仓库，Release 附件可直接下载。

附件 `Miaopu-0.0.4-unsigned.ipa` 为 **未签名 IPA**，需由使用者自行签名后安装；`.sha256` 文件用于校验下载完整性。

本版通过 macOS CI 的 24 项单元测试、iOS 模拟器界面测试、iPhoneOS 构建、无签名校验与图标校验。按既定安排不做实机验证：真实账号下的评分与评论提交、设备小组件与相册权限行为需在签名安装后确认。技术统计接口对已结束的多数场次返回空数据，相应标签不会出现。当前覆盖五类赛事，更新检查尚未实现。
