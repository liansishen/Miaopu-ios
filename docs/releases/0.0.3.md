喵扑 iOS 0.0.3：比赛详情与选手评分页按安卓版重做。

- 比赛详情改为卡片流：英雄卡（赛事介绍、状态、队标与 36pt 比分）、评分/数据标签页、全场评分卡、单局与队伍标签、排序选择器，以及带头像、英雄小图、简介、标签、均分与热评的选手卡片。
- 新增技术统计标签页：地图切换与每队统计表，选手列固定、统计列横向滚动；接口没有统计时不显示该标签。
- 选手评分页改为资料卡、评分分布（10/8/6/4/2 分条形）、我的评分（5 星）与「全部评论」列表，评论支持最热/最新排序、图片预览与保存、回复预览与回复列表。
- 评分数据解析补充选手简介、标签、评分分布、我的评分、英雄图与队伍编号，并新增队伍分组与组内对象接口；切换单局或分组时使用比赛级响应内嵌的选手立即展示。
- 评论模型补充头像、评分徽章、日期、位置与回复预览，并接入热门评论接口。

附件 `Miaopu-0.0.3-unsigned.ipa` 为 **未签名 IPA**，需由使用者自行签名后安装；`.sha256` 文件用于校验下载完整性。

本版通过 macOS CI 的 24 项单元测试、iOS 模拟器界面测试及 iPhoneOS 构建与无签名校验。按既定安排不做实机验证；真实账号下的评分与评论提交、设备小组件与相册权限行为需在签名安装后确认。技术统计接口目前对已结束的多数场次返回空数据，相应标签不会出现。当前覆盖五类赛事，更新检查尚未实现。
