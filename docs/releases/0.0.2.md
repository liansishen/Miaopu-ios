喵扑 iOS 0.0.2：按原版补齐图片与评分页面。

- 赛程与评分列表显示队标、国旗与选手头像，图片地址统一走 HTTPS 并只接受虎扑域名。
- 首页把已订阅赛事合并成近期赛程，取本机今天前后各两天，按日期与开赛时间排列，并在「近期赛程」标题旁提供刷新按钮。
- 赛事页按接口日期分组展示各项目赛程。
- 比赛详情改为原版布局：联赛与状态、双队队标、大比分与比赛时间，并接入全场评分卡与焦点评分入口。
- 选手评分页提供队伍筛选、热门/最新/高分/低分排序，以及带头像、英雄小图、数据简介、均分、评分人数和热评的选手卡片。
- 修复评分接口因缺少请求头返回 403 导致评分不显示的问题；比赛级评分改用综合评分人数。

附件 `Miaopu-0.0.2-unsigned.ipa` 为 **未签名 IPA**，需由使用者自行签名后安装；`.sha256` 文件用于校验下载完整性。

本版通过 macOS CI 的 18 项单元测试、iOS 模拟器界面测试及 iPhoneOS 构建与无签名校验。尚未进行实机验证；真实账号操作、设备小组件与相册权限行为需在签名安装后验证。当前覆盖五类赛事，更新检查尚未实现。
